# A07

This directory contains work related to assignment A07.

## Usage instructions
The full workflow requires the Mamba package manager and POV-Ray rendering engine to be installed on your system and available from the shell.

```cmd
:: clone the repository
git clone https://github.com/kalinapetrcuni/ci2.git

:: navigate into the repository
cd ci2

:: create a mamba enviroment with dependencies
mamba create -f env.yml

:: activate the enviroment
mamba activate ci2_A07

:: navigate into the A07 folder within the repository
cd A07

:: run the script
python ala5.py ala5.smi
```


The `ala5.pov` file generated by the script was then copied and modified yielding the file `edited_ala5.pov`. (The last line rendering an extra instance of the molecule was commented out)


```
:: render the image using POV-Ray (your path to the POV-Ray engine executable may differ)
"C:\Program Files\POV-Ray\v3.7\bin\pvengine64.exe" ala5_pov.ini
```

## Content description
`ala5.smi` - source SMILES code for alanine
`ala5.py` - Python script to convert a SMILES file into a .pov POV-Ray scene description of the molecule
`ala5.pov` - result of the `ala5.py` script
`edited_ala5.pov` - manually edited version (the rendering of the molecule within the file removed)
`ala5_pentagon.pov` - POV-Ray scene description with 5 instances of the molecule located at the vertices of a regular pentagon
`ala5_pentagon.png` - resulting image (`ala5_pentagon.pov` rendered by POV-Ray)
`babel_povray3.inc` - helper include file to render molecule scenes
`env.yml` - YAML file with Mamba enviroment specification
`ala5_pov.ini` - text file with POV-Ray cmd-line options (see Usage instructions)
